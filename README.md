# 💥 Personal Portfolio Website

> Every developer has a story. Here's mine, one panel at a time.

A personal portfolio website inspired by the vibrant world of comic books. Built using **HTML, CSS, and JavaScript**, it showcases my introduction, technical skills, projects, and contact information through a creative comic-book panel design.

## 🎨 About the Project

This portfolio reimagines the traditional developer portfolio with a comic-book-inspired interface, featuring bold panels, expressive visuals, and interactive elements.

The goal is to combine creative storytelling with a clean, engaging user experience while presenting my technical skills and projects.

## ✨ Features

- 💥 Comic-book-inspired panel layout and visual design.
- 🎨 Custom styling with CSS.
- ⚡ JavaScript-powered interactivity.
- 🛠️ Dedicated sections for skills and projects.
- 👨‍💻 Personal introduction and developer profile.
- 📬 Contact information and social links.
- 📱 Responsive layout for different screen sizes.

## 🧰 Tech Stack

- **HTML5** — Structure and content.
- **CSS3** — Styling, layouts, and visual effects.
- **JavaScript** — Interactive functionality.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/kshitizSrivastava05/MY_PORTFOLIO-COMIC-THEME-
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or run it using the Live Server extension.
